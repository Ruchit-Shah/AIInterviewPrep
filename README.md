# AIInterviewPrep
AI-powered SwiftUI iOS application for technical interview preparation, coding practice, and learning modern iOS development concepts.

AIInterviewPrep

AIInterviewPrep is a SwiftUI-based iOS application designed to help developers prepare for technical interviews with a clean and scalable architecture.

Short Description

A modern SwiftUI iOS app for AI-powered interview preparation and practice.

Features

* SwiftUI based user interface
* Clean and scalable project structure
* iOS native application
* Unit testing support
* UI testing support
* Beginner friendly setup
* Lightweight and easy to extend

Tech Stack

* Swift
* SwiftUI
* Xcode
* MVVM Ready Structure
* XCTest

# Requirements

* macOS
* Xcode 16 or later
* iOS 18 or later
* Swift 6

Getting Started

Clone the Repository

git clone <repository-url>

Open Project

Open AIInterviewPrep.xcodeproj in Xcode

Run the App

1. Select Simulator or Physical Device
2. Press Command + R
3. Build and Run

Testing

Run Unit Tests

Command + U
